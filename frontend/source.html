The source code of the DepthSight you are using

DepthSight is free software. The copy of it running on this website has been modified by us, and it is offered to you here as the GNU Affero General Public License v3.0 (AGPL-3.0) requires.

In plain words: because you use this service over the internet, section 13 of the AGPL-3.0 obliges us to offer you the complete source code of the modified program you are actually talking to. We make that offer to every person who interacts with this service, whether or not you have an account, and we keep it open for as long as the service is running.

  • You get the whole source code, including the changes we have made.
  • It is free of charge, and you do not need a GitHub account to download it.
  • It is the same code that is running here, not the original upstream release.

Where to get the source code

The source code of the version running on this service lives in our public repository, DiverseInc/DepthSight on GitHub:

https://github.com/DiverseInc/DepthSight

You can download it as a single archive without a GitHub account:

https://github.com/DiverseInc/DepthSight/archive/refs/heads/main.tar.gz

We do not publish a separate release package of the build we host. The repository is the source code of the running service; the archive link above is a snapshot of the tip of that same branch.

Which source code matches the version you are running

Your instance reports its own version number, and you can read it yourself. It appears in the version field of the status page:

https://depthsight.diverseinc.net/api/v1/status

and in the version field of the API description:

https://depthsight.diverseinc.net/openapi.json

The same number is written in the VERSION file at the root of the repository. The running service is deployed from the main branch of that repository, and deployments move forward as we push to main. The main branch therefore always contains the code you are talking to, and it is the exact published match for it once the most recent push has been deployed — that takes a few minutes after a push.

That version number identifies the release line, not one particular commit, and the running service does not print a commit id. The archive above is the tip of the branch, so it can be a little ahead of the build you are talking to. If you need the exact commit behind the deployment you are using, ask us by email (below) and we will send you the source code for that commit.

The upstream project this is built on

DepthSight originates in the open-source project DepthSight-Pro/DepthSight, which is licensed under the GNU Affero General Public License v3.0 (AGPL-3.0) as well. We maintain this fork and run the hosted service you are using; the relationship between the two is that of a fork and its upstream.

Upstream also asks contributors to sign a Contributor License Agreement (CLA): DepthSight-Pro/DepthSight/blob/main/CLA.md. The CLA applies to contributions made to the upstream project — signing it grants DepthSight a perpetual, worldwide, non-exclusive, royalty-free copyright licence (and a patent licence) for those contributions, and it states that the project licence is AGPLv3. The CLA does not change the terms on which we offer you this source code.

Upstream publishes its own tagged releases on GitHub. Those are upstream's own builds and are not the source code of the version running on this service.

The full licence text is the LICENSE file at the root of the repository:

https://github.com/DiverseInc/DepthSight/blob/main/LICENSE

Requesting the source code by email

If you would rather have the source code by email, or you need the exact commit for your deployment, write to us:

support@diverseinc.net

Please put AGPL source request in the subject line and tell us the version number you are running (the version field of the status page above). We will send you the source code, free of charge.

This offer applies for as long as this service is running. If the service is ever discontinued, the source code stays published in the repository above.

What "our modifications" means

The source code offered here is the source code of the running service, not the original upstream release. It contains the changes we have made to the upstream code and the code that is specific to running DepthSight as a hosted service — which is exactly what section 13 asks us to offer.
